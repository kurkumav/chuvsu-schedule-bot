# Telegram-бот расписания ИВТ-13-23

Бот получает расписание группы 8075 с https://tt.chuvsu.ru/index/grouptt/gr/8075 через доступ «Войти гостем». Логин и пароль университета не нужны.

## Бесплатный запуск на Cloudflare

В папке `cloudflare/` есть версия для **Cloudflare Workers Free + D1**: кнопки работают через webhook, подписки сохраняются в облаке, рассылка запускается Cron. После переноса компьютер можно выключать. Пошаговая инструкция: [CLOUDFLARE.md](CLOUDFLARE.md).

Из-за неполной HTTPS-цепочки сайта Cloudflare использует резервную публичную копию расписания. GitHub Actions настроен на обновление каждые 15 минут, но его запуски могут пропускаться на несколько часов. Бот показывает дату копии и предупреждение о возможном устаревании, даже если она старше трёх часов. Оба сервиса работают на бесплатных тарифах.

## Запуск на Bothost

Подключи этот репозиторий в панели Bothost, выбери Python и главный файл `bot.py`, затем укажи токен BotFather. Конфигурация языка и версии Python находится в `bothost.json`. Полная инструкция: [BOTHOST.md](BOTHOST.md).

## Запуск на Windows

1. Установи **Python 3.11 или новее** с https://www.python.org/downloads/, если его нет. При установке отметь **Add Python to PATH**.
2. Распакуй архив в отдельную папку.
3. Открой **[@BotFather](https://t.me/BotFather)** в Telegram, отправь `/newbot`, задай название и свободное имя, заканчивающееся на `bot`. BotFather выдаст токен.
4. Дважды нажми **start.bat**. Он установит библиотеки и попросит вставить токен. Символы при вводе скрыты; вставь токен и нажми Enter. Токен сохраняется в `.env` рядом с ботом.
5. Когда появится «Бот @… запущен», открой своего бота в Telegram и нажми **Start** или отправь `/start`.

**Бот отвечает, пока программа запущена, компьютер включён и подключён к интернету.** Для круглосуточной работы запусти проект на постоянно работающем компьютере или сервере. Остановка: Ctrl+C в окне бота. Повторный запуск: `start.bat`; токен повторно вводить не нужно.

- **📅 Расписание на сегодня** — пары на сегодняшнюю дату по Москве.
- **🌅 Расписание на завтра** — пары на завтра.
- **🗓 Выбрать день** — даты на ближайшие две недели. Также можно отправить дату в формате `01.10.2026`.
- **👥 Подгруппа** — 1-я, 2-я или все. Общие занятия отображаются всегда. Выбор сохраняется после перезапуска.
- **🔔 Ежедневная рассылка** — подписка на расписание дня в **07:00 по Москве**. Первое сообщение приходит в ближайшие 07:00 после включения.
- **🔕 Отключить рассылку** — отмена подписки.

Команды: `/today`, `/tomorrow`, `/days`, `/group`, `/subscribe`, `/unsubscribe`, `/help`.

## Как учитывается расписание

Учебная неделя определяется по текущей дате и номеру недели **на сайте**, с переходом на следующую неделю в понедельник. `*` означает нечётную неделю, `**` — чётную; учитываются также диапазоны вроде «2–12 нед.» и отдельные недели. Не нужно вручную задавать начало семестра.

Замены на выбранную дату выводятся с **⚠** под соответствующей парой. При замене исходная запись подписана «Основное расписание», а актуальная замена указана ниже. Это сохраняет и сложные замены с переносами, не додумывая их смысл.

Сайт проверяется по запросу с кешем до двух минут. При сбое сайта бот сообщает об ошибке. Ошибка чтения сайта не выдаётся за отсутствие пар. Авторассылка при сбое повторяет запрос раз в пять минут.

Поддерживаются обычные осенний и весенний семестры. Для сессий, ППА и ГИА бот попросит открыть сайт. Даты доступны за последнюю неделю и на 14 дней вперёд. Отдельные праздничные дни учитываются, только если их отмены опубликованы в таблице сайта.

Если бот был выключен в 07:00, после запуска он отправит расписание текущего дня. Пропущенные прошлые дни не рассылаются. Успешная рассылка сохраняется в базе, чтобы обычный перезапуск не отправлял её повторно. Если Telegram принял сообщение, но соединение оборвалось до подтверждения, повторная доставка возможна.

## Настройки

После первого запуска открой `.env` в текстовом редакторе:

```dotenv
BOT_TOKEN=токен_от_BotFather
GROUP_ID=8075
BOT_TIMEZONE=Europe/Moscow
DAILY_TIME=07:00
ALLOWED_USER_IDS=
```

`DAILY_TIME` — время ежедневной отправки. `ALLOWED_USER_IDS` — необязательный список Telegram user ID через запятую; пустое значение разрешает всем пользоваться ботом в личном чате. Для личного бота можешь указать только свой ID. Перезапусти программу после изменения настроек.

Не публикуй `.env`: это ключ управления ботом. Подписки и выбранные подгруппы хранятся локально в `data/bot.sqlite3`.

## Ручной запуск / Linux / сервер

```sh
python -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows PowerShell вместо строки выше:
# .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python setup.py
python bot.py
```

На сервере можно задать `BOT_TOKEN` переменной окружения вместо файла `.env`. Один токен должен обслуживаться одним запущенным экземпляром бота. Проект использует long polling; домен и входящий порт не нужны. Если у того же бота уже настроен webhook, программа остановится с объяснением.

## Проверка без Telegram

```sh
python bot.py --check
python bot.py --check --date 2026-10-01 --subgroup 1
python -m unittest discover -s tests -v
```

Первая команда проверяет настоящий сайт и печатает расписание на сегодня. Вторая — выбранную ближайшую дату. Тесты используют сохранённый снимок сайта от 29.09.2026 и имитацию Telegram, без токена и отправки сообщений.

Создание бота и получение токена описаны в [официальной инструкции Telegram](https://core.telegram.org/bots/tutorial#obtain-your-bot-token). Сетевые запросы выполняются с проверкой TLS через системное хранилище сертификатов.
